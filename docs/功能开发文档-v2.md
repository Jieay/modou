## 三、核心数据结构

### 3.1 文档模型（Document）

```rust
pub struct Document {
    pub path: PathBuf,
    pub rope: Rope,              // 高效文本缓冲
    pub language: Language,
    pub highlights: Vec<HighlightSpan>,
    pub cursor: Cursor,          // 光标位置
    pub is_dirty: bool,          // 修改标记
    pub read_only: bool,
}
```

### 3.2 标签页管理（TabManager）

```rust
pub struct TabManager {
    pub tabs: Vec<Tab>,          // 所有打开的标签
    pub active_index: usize,     // 当前活动标签
    next_id: usize,
}
```

### 3.3 终端管理（TerminalManager）

```rust
pub struct TerminalManager {
    pub terminals: Vec<TerminalTab>,
    pub active_index: usize,
    next_id: usize,
}
```

### 3.4 应用状态（ModouApp）

```rust
pub struct ModouApp {
    project: Option<Project>,
    tabs: TabManager,
    terminals: TerminalManager,
    search_state: SearchState,
    command_palette: CommandPaletteState,
    lsp_manager: LspManager,
    git_status: Option<GitStatus>,
    theme: Theme,
    settings: Settings,
}
```

## 五、配置文件

路径：`~/Library/Application Support/modou/settings.toml`

```toml

theme = "dark"
font_family = "JetBrains Mono"
font_size = 14

[editor]
tab_size = 4
max_file_size_mb = 20

[terminal]
shell = "/bin/zsh"
font_size = 13
```

## 六、打包与分发

### 构建命令

```bash
# Debug 构建
cargo build

# Release 构建
cargo build --release

# 打包 .app 和 .dmg
cargo bundle --release
```

### 输出文件

- `target/release/bundle/osx/墨斗.app` (19MB)
- `target/release/bundle/dmg/墨斗.dmg` (5.4MB)

## 七、已知限制与后续规划

### 当前限制

1. **LSP 功能不完整**：仅实现客户端框架，未实现完整的协议通信
2. **终端渲染基础**：不支持复杂 VT 特性（鼠标事件、真彩色渐变）
3. **无插件系统**：不支持第三方扩展
4. **无调试器**：不支持断点调试

### 后续规划

- [ ] 完整 LSP 客户端（自动补全、跳转定义、悬浮提示）
- [ ] 终端真彩色与鼠标支持
- [ ] 分屏编辑（垂直/水平分割）
- [ ] 插件系统（WASM 或 Lua）
- [ ] 调试器集成（DAP 协议）
