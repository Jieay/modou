# 墨斗（Modou）功能开发文档

> 版本：v0.1.0
> 定位：只读代码查看器 + 原生终端工作台
> 平台：macOS（Apple Silicon / Intel）
> 技术栈：Rust + Iced + Tree-sitter + alacritty_terminal

---

## 一、文档目的

本文档是墨斗 v0.1.0 的**实施级开发文档**，用于指导具体编码工作。文档将产品方案转化为可执行的技术设计，包括模块划分、数据结构、接口定义、状态流转和任务分解。

**目录扫描规则**：

### 4.5 终端模块（`terminal/`）

**职责**：PTY 创建、终端仿真、输入输出桥接。

**核心结构**：

```rust
pub struct TerminalManager {
    pub terminals: Vec<Terminal>,
    pub active_index: usize,
}

pub struct Terminal {
    pub id: TerminalId,
    pub pty: Pty,
    pub term: alacritty_terminal::Term,
    pub grid: TerminalGrid,
    pub title: String,
}

pub struct Pty {
    pub master: File,
    pub child: Child,
    pub size: Winsize,
}

pub struct TerminalGrid {
    pub cols: u16,
    pub rows: u16,
    pub cells: Vec<Cell>,
}

pub struct Cell {
    pub char: char,
    pub fg: Color,
    pub bg: Color,
    pub bold: bool,
    pub italic: bool,
    pub underline: bool,
}
```

**关键接口**：

```rust
impl Terminal {
    pub fn new(shell: &str, size: (u16, u16)) -> Result<Self, TerminalError>;
    pub fn write_input(&mut self, data: &[u8]) -> Result<(), TerminalError>;
    pub fn read_output(&mut self) -> Result<Vec<u8>, TerminalError>;
    pub fn resize(&mut self, cols: u16, rows: u16) -> Result<(), TerminalError>;
    pub fn render_grid(&self) -> &TerminalGrid;
}
```

**终端启动流程**：
1. 读取 `$SHELL` 环境变量，默认 `/bin/zsh`
2. 创建 PTY master/slave 对
3. fork 子进程，在子进程中 setsid + 打开 slave + exec shell
4. 父进程保留 master，设置非阻塞读取
5. 启动 tokio task 轮询 master 读取输出
6. 将输出送入 alacritty_terminal 解析 VT 序列
7. 从 alacritty_terminal 的 Grid 中读取 Cell 渲染到 GUI

**环境变量设置**：
```rust
env.insert("TERM", "xterm-256color");
env.insert("COLORTERM", "truecolor");
env.insert("LANG", "zh_CN.UTF-8"); // 或系统语言
```

### 4.8 UI 组件（`ui/widgets/`）

#### 4.8.1 文件树组件（`file_tree.rs`）

**职责**：渲染目录树、处理点击事件。

**渲染规则**：
- 每行显示缩进 + 图标 + 文件名
- 目录使用 📁 图标，文件使用 📄 图标
- 展开的目录显示 ▼，折叠显示 ▶
- 当前选中项高亮背景

**交互**：
- 单击目录：展开/折叠
- 单击文件：加载到编辑器
- 右键菜单（第一版可不做）：打开、在终端中打开

#### 4.8.2 编辑器组件（`editor.rs`）

**职责**：渲染文本内容、行号、高亮。

**渲染规则**：
- 左侧显示行号，宽度自适应最大行数
- 文本使用等宽字体，按 HighlightSpan 着色
- 支持水平/垂直滚动
- 当前行背景微亮

**性能优化**：
- 仅渲染视口内可见行
- 使用 `cosmic-text` 进行文本布局
- 滚动时增量计算可见区域

#### 4.8.3 终端组件（`terminal.rs`）

**职责**：渲染终端网格、处理输入。

**渲染规则**：
- 等宽字体渲染 Cell 字符
- 根据 Cell 的 fg/bg 着色
- 光标位置闪烁显示

**交互**：
- 键盘输入直接写入 PTY master
- ⌘+V 粘贴
- 鼠标滚动发送滚动事件到终端

#### 4.8.4 状态栏组件（`status_bar.rs`）

**显示内容**：
- 左侧：当前文件路径
- 中间：行数、列数、文件大小
- 右侧：当前语言、终端状态

## 六、错误处理策略

### 6.1 错误类型定义

```rust
#[derive(Debug, thiserror::Error)]
pub enum ModouError {
    #[error("IO error: {0}")]
    Io(#[from] std::io::Error),

    #[error("Project error: {0}")]
    Project(String),

    #[error("Document error: {0}")]
    Document(String),

    #[error("Highlight error: {0}")]
    Highlight(String),

    #[error("Terminal error: {0}")]
    Terminal(String),

    #[error("Config error: {0}")]
    Config(String),
}
```

### 6.2 错误处理原则

- **文件不存在**：状态栏显示错误提示，不崩溃
- **权限不足**：提示用户检查文件权限
- **文件过大**：超过 20MB 弹出确认对话框
- **终端启动失败**：显示错误信息，允许重试
- **Tree-sitter 解析失败**：降级为纯文本显示，不高亮

### 6.3 日志策略

- 使用 `tracing` 记录关键事件
- 日志文件：`~/Library/Logs/modou/modou.log`
- 日志级别：开发时 `debug`，发布时 `info`

## 七、性能优化策略

### 7.1 启动优化

- 懒加载 Tree-sitter parser：仅在打开对应语言文件时初始化
- 异步扫描目录：使用 tokio task 扫描大目录
- 预加载默认字体和主题

### 7.2 渲染优化

- 编辑器：仅渲染视口内可见行
- 终端：仅在内容变化时重绘
- 使用 Iced 的 `Cache` 缓存静态内容

### 7.3 内存优化

- 文件内容按需加载，不一次性读入所有打开的文件
- Tree-sitter 语法树仅保留当前文件
- 终端历史记录限制 10,000 行

## 十二、风险与应对

| 风险 | 应对 |
|------|------|
| alacritty_terminal 集成困难 | 第 2 周并行预研，若阻塞则降级为简易 VT 解析 |
| Iced 自定义渲染性能不足 | 第 3 周做性能测试，必要时改用 `wgpu` 直接渲染 |
| Tree-sitter 版本不兼容 | 固定版本号，升级前跑冒烟测试 |
| 大文件打开卡顿 | 行区间懒加载 + 视口外截断 |
| 打包后 Gatekeeper 拦截 | 文档中说明右键打开方式，后续考虑签名 |
